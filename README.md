# Mój Dzień – darmowy build APK

1. Załóż darmowe konto na github.com i utwórz nowe repozytorium.
2. Wgraj do niego CAŁĄ zawartość tego folderu (razem z ukrytym folderem .github).
3. Wejdź w zakładkę Actions, poczekaj ok. 5 min na zielony ptaszek.
4. Wejdź w ukończone uruchomienie, pobierz artefakt "apk", rozpakuj i zainstaluj app-debug.apk na telefonie.

Cytaty edytujesz w www/index.html (tablica Q), tematy newsów dodajesz w samej apce.
